# 🔹 i. Directory Services (Identity & Security)

These manage **users, authentication, and access control** in a network.

### 1. ADCS (Active Directory Certificate Services)

👉 Provides **digital certificates** for security
✔ Used for encryption, SSL, secure login
📌 Example: HTTPS websites, secure emails

---

### 2. ADDS (Active Directory Domain Services)

👉 The **core directory service**
✔ Stores users, computers, passwords
✔ Handles login (authentication)

📌 Example: Logging into a domain PC using username/password

---

### 3. ADFS (Active Directory Federation Services)

👉 Provides **Single Sign-On (SSO)**
✔ Login once → access multiple apps/services

📌 Example: Login once and access Office 365 or other apps

---

### 4. ADLDS (Active Directory Lightweight Directory Services)

👉 A **lighter version of ADDS**
✔ Used by applications instead of full domain

📌 Example: App needs directory without full domain setup

---

### 5. ADRMS (Active Directory Rights Management Services)

👉 Protects **sensitive data from misuse**
✔ Controls who can open/edit/print files

📌 Example: Restrict a document from being copied or forwarded

---

# 🔹 ii. Infrastructure Services (Network & System Support)

These support **network communication and resource management**

---

### 1. DHCP (Dynamic Host Configuration Protocol)

👉 Automatically assigns **IP addresses**

📌 Example: When your laptop connects to WiFi and gets an IP

---

### 2. DNS Server (Domain Name System)

👉 Converts **domain names → IP addresses**

📌 Example: google.com → 142.250.x.x

---

### 3. Hyper-V

👉 Microsoft’s **virtualization platform**
✔ Run multiple virtual machines on one system

📌 Example: Run Kali Linux inside Windows Server

---

### 4. NPAS (Network Policy and Access Services)

👉 Controls **who can access the network**

✔ Authentication + authorization
✔ Enforces network policies

📌 Example: Only employees can connect to company VPN

---

### 5. HRA (Health Registration Authority)

👉 Checks **device health before allowing access**

✔ Works with Network Access Protection (NAP)

📌 Example: Only updated antivirus systems can connect

---

# 🔹 iii. Application Services

👉 Provides platform to **run and manage applications**

✔ Includes web apps, enterprise apps, services

📌 Example:

* Web server (IIS)
* Application hosting
* API services

---

# 🔥 Easy Way to Remember

* **Directory Services → WHO you are (Identity)**
* **Infrastructure Services → HOW network works**
* **Application Services → WHAT runs on server**
