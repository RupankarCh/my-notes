Encoding: Transforming data from one format to another for storage or transmission.

Executable vs. Non-Executable Files: Executables (.exe, .bat) contain runnable instructions, while non-executable files store static data.

Python, PyPI, & Dependencies: Python is an object-oriented scripting language; PyPI is its package index, and dependencies are external packages required for a project to run.

API & API Key: An interface allowing different software systems to talk to each other, secured via a unique authentication key.

Source Code (Open vs. Closed): Open source allows public code viewing/collaboration (e.g., Linux), while closed source keeps code private (e.g., Windows).

IDE: An integrated development environment with rich coding tools, syntax highlighting, and debugging features.

Version Control (Git & Bitkeeper): Systems to track code changes and collaboration.

Winget: Microsoft's open-source package manager for Windows 10/11.
