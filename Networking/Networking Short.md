Servers: Programs that supply requested data; the central information hub. (Clients are programs that ask servers for things).

Web Server: A mix of hardware and software (like Apache or NGINX) that keeps web apps running and serves web pages via HTTP requests.

Database Server: A program specifically designed to offer and manage databases.

Email Server: Software that handles sending, receiving, and storing emails using protocols like SMTP, IMAP, and POP3.

Linux Server: A computer running a Linux OS (often rented via AWS, Digital Cloud, etc.) primarily used to host server software.

Session: A single, continuous series of interactions between a user and a server.

Sockets: An OS feature that allows different programs or servers to connect and communicate.

Name Server (NS) / DNS: Translates human-readable domain names into numerical IP addresses.

SPF (Sender Policy Framework): A DNS record specifying which mail servers are allowed to send emails for your domain.

TXT Records: DNS records used to store text for security, authentication, and verification.

CNAME Record: A DNS alias record that maps one domain name to point to another.

SOA (Start of Authority) Record: A DNS record containing admin settings and key zone info for a domain.

Root Domain & TLD: The root domain is a website's main name, and the TLD (Top-Level Domain) is the suffix extension (like .com or .org).

OSI Model: A 7-layer conceptual framework standardizing network communication.

Network Topologies: The physical/logical layout of network devices (star, bus, ring, mesh).

Common Protocols & Ports: Standard rules (HTTP, TCP, etc.) and communication endpoints (Port 80 for HTTP, 443 for HTTPS).

IPv4 & IPv6: Internet addressing schemes (32-bit vs. 128-bit addresses).

Subnetting: Dividing a network into smaller sub-networks for better performance and security.

Onion Routing & Tor Project: Multi-layered encryption routing data through random volunteer nodes for anonymity.
