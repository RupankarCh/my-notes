## Encryption & Decryption: 

✔ Encryption: Converts readable plaintext into unreadable ciphertext using cryptographic algorithms to ensure confidentiality.  
✔ Decryption: Converts ciphertext back into plaintext using a secret key. 

## Hashing:
**Converts data into a fixed-length hash value using a one-way function**, ensuring integrity. **Used in password storage, data integrity checks, and digital signatures**. Because it is hashed into a fixed length value the hash value can't directly be reversed.
