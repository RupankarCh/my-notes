# Markdown Cheat Sheet

## 1. Headings

```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
```

## 2. Bold and Italic

```markdown
**Bold text**

*Italic text*

***Bold and Italic***
```

Result:
**Bold text**
*Italic text*
***Bold and Italic***

---

## 3. Lists

### Unordered List

```markdown
- Item 1
- Item 2
  - Sub item
```

### Ordered List

```markdown
1. First item
2. Second item
3. Third item
```

---

## 4. Links

```markdown
[Google](https://www.google.com)
```

---

## 5. Images

```markdown
![Alt text](image.png)
```

---

## 6. Code

### Inline Code

```markdown
Use `print()` function
```

### Code Block

````markdown
```python
print("Hello World")
````

````

## 7. Blockquotes
````

## 9. Tables

## 10. Task Lists

```markdown

```

