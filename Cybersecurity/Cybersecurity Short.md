Session Hijacking: Stealing a user’s session cookie to impersonate them without a password.

Backdoor Shell & Shellcode: Malicious code or scripts injected to gain unauthorized remote access.

Active Directory: A database used by IT teams to manage user access and permissions on a network.

SOC (Security Operations Center): A central team/unit monitoring and protecting an organization's IT security environment.

White Box vs. Black Box Testing: White box testers know everything about the system; black box testers act like external hackers with zero prior knowledge.

Scanning & Recon: Zombie scans, Nmap scripting engine, RST packets, vulnerability scanners, and content scanners used to map targets and find flaws.

SQL Injection: Injecting malicious database queries into input fields to steal or modify data.

Cyber Hackers (White, Black, Grey Hat, Script Kiddies, etc.): Classifications of hackers based on intent and skills (ethical vs. malicious).

CIA Triad: The core security model focusing on Confidentiality, Integrity, and Availability.

OWASP Framework: Best practices and standards for securing web applications.

OSINT: Open Source Intelligence gathering from public sources.

Post-Exploitation (Pivoting & Persistence): Moving across compromised networks and maintaining long-term access.
