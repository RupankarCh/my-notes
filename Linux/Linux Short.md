Kernel: The core bridge between computer hardware and software, managing memory, CPU, and security.

Monolithic Kernel: High performance with most OS functions built-in.

Micro Kernel: Handles basics with drivers outside the core; can crash isolated parts without breaking the whole OS.

Kernel Panic: A critical system crash where the OS hits an unstable state and halts completely.

Linux & Distributions (Distros): An open-source Unix-like OS; distributions (like Ubuntu, Fedora) package the Linux kernel with tools, package managers, and UIs (GNOME, KDE).

File System & Inodes: Manages how data is stored/fetched on disks; every file/directory is tracked by an Inode Number.

Boot Loader & GRUB: The startup program (executed by BIOS/UEFI) that loads the OS into memory.

Shell & Shebang: A command-line interface to interact with the OS. The Shebang (#!/bin/bash) tells the OS which shell to use for a script.

Permissions & Tools (Sticky Bit, Umask): Controls who can delete or modify files/directories.

Hibernation: Saving the entire RAM state to disk so the computer can power completely off and resume later.

Journaling: A file system feature that helps auto-repair data after an improper shutdown.

WSL & XRDP: Tools enabling Windows Subsystem for Linux and remote desktop access.

32-bit / 64-bit: Processor and OS architectures determining processing power and memory capacity.
